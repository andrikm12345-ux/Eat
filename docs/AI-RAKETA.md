# ИИ-настройки «Ракета» (быстрая рабочая версия)

Кодовое слово: **Ракета**. Метка в git: `ai-raketa` (коммит `bacbb24`).
Если после изменений ИИ снова «тупит», скажите «верни Ракету»: файлы ИИ возвращаются к этой версии.

## Что входит в «Ракету»

Модель и сервис (общий ИИ для всех пользователей, ключ только в переменных Vercel):
- сервис: `https://tokenharbor.ai/v1`, модель текста и фото: `mimo-v2.6-flash:free`
  (в коде это значения по умолчанию; переменные Vercel `AI_BASE_URL`, `AI_MODEL_TEXT`,
  `AI_MODEL_VISION` и файл `config/ai.json` в хранилище могут их переопределять);
- дневной лимит 60 запросов на человека (`AI_DAILY_LIMIT`).

Сервер (`server/sharedAi.ts`):
- просит модель не «думать» (`reasoning_effort`, `reasoning`, `thinking`, `enable_thinking`,
  `chat_template_kwargs`), при ответе 400/422 повторяет запрос без этих полей;
- потолок ответа: 4000 токенов для текста, 6000 для фото;
- обрыв запроса к сервису ИИ на 87 с, ошибка таймаута узнаётся по имени.

Приложение:
- ожидание ответа ИИ: 92 с (`src/ai/client.ts`);
- описание словами: через 20 с показывается быстрый результат по каталогу, позже ИИ
  присылает уточнение всплывающим сообщением (`AiTextPage`, `src/features/ai/upgrade.ts`);
- короткие запросы (`src/ai/prompts.ts`): компактный JSON в одну строку, необязательные
  поля только при необходимости, без самопроверки и длинных абзацев про масштаб;
- фото: 1024 px (768 px, если фото несколько), качество 0,72;
- интернет-справка для ИИ: не больше 3 результатов по 350 символов;
- одиночный точный продукт из каталога без количества берётся сразу, без ИИ.

## Как вернуть

Только код ИИ (оформление остаётся как есть):

    git checkout ai-raketa -- server/sharedAi.ts server/deps.ts src/ai src/features/ai \
      src/services/mealParts.ts src/services/mealText.ts
    npm run build && npx vitest run   # потом commit и push

Переменные Vercel (модель, адрес) проверьте отдельно: они не хранятся в git.
